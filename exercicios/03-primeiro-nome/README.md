# Exercício 3 — Primeiro nome

**Dificuldade:** fácil  
**Pratique:** arrays, tipo `string[]`, índices e retorno de função

## Objetivo

Crie uma função chamada `primeiroNome` que receba uma lista de nomes e devolva o primeiro nome da lista.

## Requisitos

- A função recebe um array de strings.
- A função devolve uma `string`.
- Considere que a lista sempre terá pelo menos um nome.

## Exemplos

| Entrada | Saída esperada |
| --- | --- |
| `["Ana", "Rui"]` | `"Ana"` |
| `["Lia"]` | `"Lia"` |

Escreva sua tentativa em `index.ts`. Pense em como acessar uma posição específica de um array. Se travar, peça uma pista por vez.
