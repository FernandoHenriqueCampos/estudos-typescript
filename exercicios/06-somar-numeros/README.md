# Exercício 6 — Somar números

**Dificuldade:** fácil  
**Pratique:** arrays de números, laço `for` e acumulador

## Objetivo

Crie uma função chamada `somarNumeros` que receba uma lista de números e devolva a soma de todos eles.

## Requisitos

- A função recebe um array de números.
- A função devolve um `number`.
- Some todos os valores, incluindo os negativos e o zero.
- Se a lista estiver vazia, devolva `0`.

## Exemplos

| Entrada | Saída esperada |
| --- | --- |
| `[4, -2, 0, 7]` | `9` |
| `[-3, -1]` | `-4` |
| `[]` | `0` |

Escreva sua tentativa em `index.ts`. Pense em qual valor inicial permite que a soma funcione também para uma lista vazia. Se travar, peça uma pista por vez.
