# Exercício 8 — Maior número

**Dificuldade:** fácil  
**Pratique:** arrays de números, laço `for`, condições e acompanhamento de um valor

## Objetivo

Crie uma função chamada `maiorNumero` que receba uma lista de números e devolva o maior valor.

## Requisitos

- A função recebe um array de números.
- A função devolve um `number`.
- Considere que a lista sempre terá pelo menos um número.
- A lista pode conter números negativos.

## Exemplos

| Entrada | Saída esperada |
| --- | --- |
| `[4, -2, 0, 7]` | `7` |
| `[-8, -3, -12]` | `-3` |
| `[5]` | `5` |

Escreva sua tentativa em `index.ts`. Pense em qual valor guardar enquanto percorre a lista e quando ele deve mudar. Se travar, peça uma pista por vez.
