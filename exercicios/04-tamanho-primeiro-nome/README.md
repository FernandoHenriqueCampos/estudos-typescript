# Exercício 4 — Tamanho do primeiro nome

**Dificuldade:** fácil  
**Pratique:** arrays, strings, índices, propriedade `length` e retorno de função

## Objetivo

Crie uma função chamada `tamanhoPrimeiroNome` que receba uma lista de nomes completos e devolva quantas letras tem o primeiro nome da primeira pessoa da lista.

## Requisitos

- A função recebe um array de strings.
- A função devolve um `number`.
- Considere que a lista sempre terá pelo menos um nome e que cada nome começa pelo primeiro nome.
- Conte apenas as letras do primeiro nome; não conte o sobrenome nem os espaços.

## Exemplos

| Entrada | Saída esperada |
| --- | --- |
| `["Ana Luiza", "Rui"]` | `3` |
| `["Isabela Costa"]` | `7` |

Escreva sua tentativa em `index.ts`. Pense em como descobrir o tamanho de uma string. Se travar, peça uma pista por vez.
