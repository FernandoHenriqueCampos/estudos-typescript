# Exercício 7 — Média dos números

**Dificuldade:** fácil  
**Pratique:** arrays de números, laço `for`, acumulador e divisão

## Objetivo

Crie uma função chamada `calcularMedia` que receba uma lista de números e devolva a média deles.

## Requisitos

- A função recebe um array de números.
- A função devolve um `number`.
- Considere que a lista sempre terá pelo menos um número.
- A média deve incluir todos os números, inclusive os negativos e o zero.

## Exemplos

| Entrada | Saída esperada |
| --- | --- |
| `[4, 6, 8]` | `6` |
| `[2, 3]` | `2.5` |
| `[-2, 4]` | `1` |

Escreva sua tentativa em `index.ts`. Pense em qual valor você precisa acumular e em quantos números há na lista. Se travar, peça uma pista por vez.
