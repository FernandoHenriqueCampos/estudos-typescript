# Exercício 1 — Saudação

**Dificuldade:** bem fácil  
**Pratique:** tipos `string`, parâmetros e retorno de função

## Objetivo

Crie uma função chamada `saudacao` que receba um nome e devolva uma saudação personalizada.

## Requisitos

- A função recebe um parâmetro do tipo `string`.
- A função devolve um valor do tipo `string`.
- A saudação deve incluir o nome recebido.

## Exemplos

| Entrada | Saída esperada |
| --- | --- |
| `"Ana"` | `"Olá, Ana!"` |
| `"Rui"` | `"Olá, Rui!"` |

Escreva sua tentativa em `index.ts`. Primeiro tente sem pedir uma pista. Se travar, peça só uma dica sobre o conceito que está causando dúvida.
