# Exercício 2 — Classificar um número

**Dificuldade:** fácil  
**Pratique:** tipo `number`, condições (`if` / `else`) e retorno de função

## Objetivo

Crie uma função chamada `classificarNumero` que receba um número e devolva se ele é positivo, negativo ou zero.

## Requisitos

- A função recebe um parâmetro do tipo `number`.
- A função devolve uma `string`.
- Para um número maior que zero, devolve `"positivo"`.
- Para um número menor que zero, devolve `"negativo"`.
- Para zero, devolve `"zero"`.

## Exemplos

| Entrada | Saída esperada |
| --- | --- |
| `8` | `"positivo"` |
| `-3` | `"negativo"` |
| `0` | `"zero"` |

Escreva sua tentativa em `index.ts`. Pense em como separar os três casos usando condições. Se travar, peça uma pista por vez.
