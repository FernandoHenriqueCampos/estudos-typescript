# Exercício 5 — Contar números positivos

**Dificuldade:** fácil  
**Pratique:** arrays de números, laço `for`, condições (`if`) e contador

## Objetivo

Crie uma função chamada `contarPositivos` que receba uma lista de números e devolva quantos deles são positivos.

## Requisitos

- A função recebe um array de números.
- A função devolve um `number`.
- Conte apenas os números maiores que zero. O zero não é positivo.
- Se a lista estiver vazia, devolva `0`.

## Exemplos

| Entrada | Saída esperada |
| --- | --- |
| `[4, -2, 0, 7]` | `2` |
| `[-3, 0, -1]` | `0` |
| `[]` | `0` |

Escreva sua tentativa em `index.ts`. Pense em como visitar cada número da lista e manter a quantidade encontrada. Se travar, peça uma pista por vez.
